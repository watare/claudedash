## Getting Started

### Prerequisites
- Node.js 18+
- Claude Code CLI installed and authenticated

### Quick Start

```bash
# Install dependencies
npm install
cd dashboard && npm install && cd ..

# Configure (optional)
cp bmad-orchestrator.secrets.example.yaml bmad-orchestrator.secrets.yaml

# Build dashboard
cd dashboard && npm run build && cd ..

# Start server
npm start
```

### Development

```bash
# Server with auto-reload
npm run dev

# Dashboard dev server
cd dashboard && npm run dev
```

### Running Tests

```bash
# Server tests
npm test

# Dashboard tests
cd dashboard && npm test
```

## Key Features

1. **Multi-Project Orchestration** - Manage multiple BMAD projects from one dashboard
2. **Parallel Execution** - Run epics/stories in configurable batch sizes
3. **Real-time Monitoring** - WebSocket-powered live status updates
4. **Supervisor AI** - Intelligent question handling via Claude 3.5 Haiku
5. **Agent Management** - Start, stop, kill agents with stuck detection
6. **Execution History** - SQLite-backed audit trail of all runs
7. **Authentication** - GitHub OAuth and password-based login
