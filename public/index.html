BMAD Orchestrator runs your epics and stories in parallel using Claude Code.


Flow:

  1. Epics run in batches (e.g., Epic 1+2)
  2. For each epic: create all story files first
  3. Then run all stories in parallel
  4. Each story: branch → dev → review → PR
  5. When all stories done: merge PRs, test

This dashboard will keep running even if you disconnect.
